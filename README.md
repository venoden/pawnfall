# dungeon-crawler-prototype

Private Godot 2D dungeon crawler prototype.

## Current Status
Early playable prototype.

## Current Version
v0.0.0-alpha.1

## Features
- Playable Pawn character
- Goblin enemies
- Goblin boss
- Mace starting weapon
- Bluntbow pickup weapon
- Torch and health pickups
- Pause, Victory, and Defeated screens

## Versioning
This project uses semantic prerelease-style tags.
Prototype builds use v0.0.0-alpha.#.
More stable foundation builds will move to v0.0.1-alpha.#.
Larger playable milestones may later use v0.1.0-alpha.#.

## Development Notes
This repo is experimental and patch-sized changes are preferred.
Avoid large refactors unless needed.
